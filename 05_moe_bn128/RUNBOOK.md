# Как подать 4bc

Порядок как в `01_w8_rowsplit/RUNBOOK.md`. Здесь отличия.

## 0. До начала

1. `gh` под `MichaelDementii`, `gh` и `git` в PATH, Python 3.10+.
2. **Свободный слот** — апстрим держит не больше двух открытых вещей от одного человека.
3. **Подавать после кандидата 3 и после 4a.** Не потому что зависит по коду — не зависит, ветка
   стоит прямо на `1fc1cb76`, — а потому что 4a раскрывает широкий чанк, ради которого эта правка и
   нужна, и потому что вместе они дают больше, чем по отдельности.

## 1. Порядок

```
python make_pr.py check
python make_pr.py issue --yes
# ждём ответа
python make_pr.py fetch --yes
python make_pr.py push  --yes
python make_pr.py create --yes
```

## 2. Ветка

`perf/moe-wide-bn` = **`786db14f`**, один коммит на `1fc1cb76`, 2 файла, +89/−43.
`branch.bundle` тонкий, голова сверяется `EXPECT_COMMIT`.

**Дерево этого коммита байт в байт то, на котором сняты все числа** (замеры шли на `1bac2234`,
`--amend` поменял только сообщение; деревья сверены, оба `e6103af8`).

## 3. Что решено

- Никаких `NINFER_MOE_BN` и никаких макросов запуска. Одно `constexpr`-выражение владеет и границей
  запуска, и сеткой. `nvcc` 13.1 это принимает — проверено сборкой.
- Занятость на широкой плитке падает с 3 блоков на SM до 2. Это **арифметика, а не выбор**, и в
  заявке приведены обе таблицы: сколько shared занимает плитка и почему три блока не влезают.
- Контролей два, и оба по построению: строки 1024/2048 ниже порога, а кодек `w8-w8` идёт через
  другие ядра и не может измениться в принципе.

## 4. Что открыто и написано вопросом

- **Порог 4096 не подметён.** Объяснение есть, замера нет. Если он захочет кривую — опустить
  константу и померить 2048 и 3072 на обеих ширинах плитки.
- Ширина 128 — почему не 96 и не 256.
- Занятость 3 → 2: не предпочтёт ли он более узкий `ExpertWarps`, чтобы три блока остались.

## 5. Конфликт с 4a

Обе правки трогают соседние строки `sparse_moe_prefill.h`: 4bc вставляет
`kSparseMoePrefillWideBnTokens` прямо над `kSparseMoePrefillSliceMax`, которую правит 4a. Конфликт
чисто текстовый. **Кто пойдёт вторым — тому ребейз в одну строку**, и это стоит сказать в теле
второй заявки заранее.

## 6. Данные

которого взяты числа про совместный эффект.
