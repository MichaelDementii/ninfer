## Как читать метки рук

`сводки/карта_прогонов.txt` связывает метку с идентификатором прогона EvalScope.

| метка | что это |
|---|---|
| `standard_*`, `long_64k_*`, `long_128k_*`, `long_260k_*` | «иголка», четыре профиля, **без спекуляции** |
| `aime_both_*` | AIME 2025 и 2026 одной сюитой |
| `gpqa_*` | GPQA-Diamond, семя 42 |
| `gpqaB_*`, `gpqaC_*`, `gpqaS31337_*`, `gpqaS90210_*` | GPQA, семена 4243, 777, 31337, 90210 — **контроль жребия** |
| `ifbench_*` | IFBench |
| суффикс | кодек: `bf16`, `int8`, `fp8`, `nvfp4`, `k8v4` |

Перплексия: `L_*` — авторский протокол для кодеков (полный корпус, контекст 65536,
шаг 32768); `S_*` — протокол по умолчанию (4096 / 2048); `ppl_long_*` — склеенный
документ 261 169 токенов при контексте 262144.

## Чего здесь нет

**Полных предсказаний моделей.** 41 прогон занимает 1.4 ГБ, из них почти всё — тексты
ответов. Они остались на сервере в `/root/ninfer_d4/eval/runs/`. Здесь лежат сводки,
манифесты и все журналы, по которым числа проверяются и пересчитываются.

**Ключа доступа и секретов контейнера.** Ключ SSH — в рабочем каталоге, `CONTAINER_API_KEY`
не переносился.
